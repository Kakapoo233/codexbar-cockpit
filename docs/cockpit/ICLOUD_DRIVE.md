# iCloud Drive 个人同步

本项目使用 iCloud Drive 文件交换实现个人同步，不再要求开发版具备 CloudKit 签名权限。
在「设置 → iCloud 同步」中开启，其他 Mac 使用同一 Apple 账号、启用 iCloud Drive，并安装支持此格式的版本。

## 同步内容

- 已列入白名单的显示、刷新和额度提醒设置。
- 界面语言、菜单栏英文文字选项，以及菜单栏布局和条件规则。
- 按提供商、账户和日期区分的个人额度上限。
- 日历中的个人状态和舒适度反馈。

API Key、Cookie、登录令牌、团队凭据、原始会话、提示词、日志路径、本机 Token 总量和原始额度观测不进入同步文件。
本机 Token 模式的状态可以共享，但对应的 Token 测量仍属于各自电脑。每日建议根据本机当前账户和观测重新计算。
组员与设备的 Cloudflare 同步仍是独立功能；iCloud Drive 不会自动开启团队上传。

## 同步与状态

目录为 iCloud Drive 下的 `CodexBar Cockpit/Sync-v1`。应用启动、激活和开启同步时检查，运行期间每 15 秒检查一次，也可点击「立即同步」。
每台设备写自己的 UUID 文件，以逻辑修订号合并各项设置和记录。首次加入时先采用已有云端值；不同项目的编辑可以合并，同一项目的并发编辑按确定的修订顺序选出一个值。清除状态保留删除标记，避免离线设备将它恢复。

「最近本机文件交换」只证明本机读取、应用或写入文件成功。Apple 负责上传和下载；界面另显示 Apple 提供的上传状态。上传成功也不能证明第二台 Mac 已经收到。
关闭同步停止后续交换，不删除本机记录或云端文件。

## 异常处理

未下载的 iCloud 文件会先请求下载并等待，不当作空数据。无目录、损坏文件、较新格式、读取权限不足或保存失败会显示错误，并保留本机数据。
不要通过删除同步文件或本机状态文件来解决错误；这些文件包含修订历史和删除标记。先关闭同步、备份相关目录，再根据具体提示排查。

## 验收边界

自动测试使用两个隔离客户端和合成数据，覆盖修改、清除、重连、首次加入、冲突、损坏数据、权限和停止同步。
真实跨设备完成状态仍需第二台 Mac 验证。此功能不上传登录凭据，也不承诺复制本机全部设置或历史统计。
