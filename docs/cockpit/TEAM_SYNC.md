# 组员与设备

0.6.0 将原版 Codex Cockpit 的团队功能接入原生菜单栏。菜单栏中的「组员与设备」
与统计、日历、小票同级；服务地址和连接操作位于「设置 → 组员与设备」。

## 连接

1. 使用团队已有的 Codex Cockpit v2 服务，或按照
   [云端部署说明](https://github.com/Kakapoo233/codexbar-cockpit/blob/main/cloud/usage-sync-worker/README.md) 部署自己的 Cloudflare Worker 与 D1。
   本仓库不提供公共托管服务。
2. 管理员输入 HTTPS 服务地址、空间名称、自选设备名称和服务创建密钥，创建空间。
   其他设备用同一服务地址和单次邀请码加入；邀请码默认 24 小时有效。
3. 在「组员与设备」添加成员，将每台设备分配给一位成员。成员名称可以修改，稳定 ID 保持不变。
   未分配的设备仍单独显示。每位成员可以关联多台设备，默认预算按人数分配。
4. 在设置中确认当前 Codex 账号属于这个共享空间，再绑定账号。账号额度需要是近期有效观测。
   每个空间表示一个 Codex 共享账号；不同账号应使用各自空间，不能合计额度百分比。

## 设置中的填写项

从「设置 → 组员与设备 → Cloudflare 同步」选择「使用自己的 Cloudflare」或「加入已有空间」。

| 填写项 | 从哪里获取 | 使用方式 |
| --- | --- | --- |
| Cloudflare Worker 地址 | 自己部署完成的 HTTPS `workers.dev` 地址或自定义域名；受邀用户向管理员获取 | 两种方式都需要，填写域名地址，不附加 `/v1` 等接口路径 |
| 设备显示名称 | 自行填写，例如工作 Mac、家用 Mac | 两种方式都需要 |
| 共享空间名称 | 自行填写团队名称 | 创建空间时需要 |
| 空间创建密钥 | 部署同步 Worker 时设置的 `BOOTSTRAP_SECRET` | 创建空间时需要；不是 Cloudflare API Token |
| 邀请码 | 空间所有者在「组员与设备」生成 | 加入已有空间时需要 |

「检查服务地址」只进行不含凭据的可达性和服务标识检查，不上传邀请码、创建密钥或用量。
检查成功不代表数据库或加入权限已验证；创建／加入操作会继续验证这些内容。修改地址会清除旧检查结果。
连接成功后，服务与设备配置保存在本机；创建密钥和邀请码不会写入普通配置。
更改地址、切换连接方式或离开设置页会清空尚未提交的密钥／邀请码。

「这些设置从哪里获取？」可展开步骤，并直接打开部署指南和 Cloudflare 控制台。
每位用户连接自己的部署；应用不会自动在 Cloudflare 创建资源。

## 预算

共享计划按北京时间（UTC+8）自然日冻结，不改变日历原有的统计时区。本机每日建议与共享预算
分别保存；用量页可直接看到分配给自己的团队预算。风险容忍度越高，当日建议使用量越大。
个人可以调整自己的预算，其他人的预算不被重新分摊，因此总和可能超过建议值。
保存遇到其他设备的修改时会提示重新加载，旧草稿不能跨重置周期保存。

这些数值用于协作规划和查看使用情况，不会转移服务商额度，也不会强制阻止第三方工具继续消费。

## 用量共享与隐私

默认仅同步空间、成员、设备归属与预算。上传用量需要额外确认：本机日志属于此共享账号，
且不是另一台设备日志的副本。镜像或复制同一日志的设备只选一台上传，其余设备关闭用量共享。

当前安全导出范围为现有收集器发布的原生 Codex 本机日志汇总，要求统计时区为 Asia/Shanghai。
从确认后的下一个完整北京时间自然日开始共享；不补传同意前的记录。当日和不完整扫描保留
「部分数据」标识，缺失值不会被当成零。混合补充日志、远程服务商账单、其他币种与不能可靠归属的
数据保持不可用，不会自动混入团队。上游 v2 的其他客户端可连接同一服务，但不会获得本机任务明细。

当前实现不会上传 API 密钥、提供商登录凭据、账号邮箱、目录路径、任务名称、提示词或体感记录。
账号身份改变会撤销本机共享确认；重新绑定后重新计算可共享的日期范围。关闭上传后，下一次成功
同步会用空汇总替换本设备的当前快照。暂停同步不会删除已经共享的服务器数据。

成员和服务运营者能够读取共享数据；这不是端到端加密。同步凭据只存本机 Keychain，不进入普通设置、
个人 iCloud 同步或 Git。离线时保留最后成功数据并显示错误；应用退出或电脑睡眠期间不会同步。

管理员的唯一凭据暂不支持转移或恢复，因此管理员连接只能暂停，不能通过普通“断开”丢弃。
普通成员断开后再次加入需要新邀请码；请管理员撤销旧设备记录。撤销访问不等于删除历史数据库记录。
创建或加入成功后，如果本机保存失败，请保持应用打开并使用「重试保存连接」，无需消耗新的邀请码。

## 验收范围

代码中的测试使用合成数据和临时存储。真实云部署与两台设备的创建、加入、修改冲突、离线恢复和
撤销验收，需要实际团队服务及第二台设备；尚未完成时不能视为已上线。新增团队界面提供英文、简体
和繁体中文，其余现有语言暂回退为英文，不影响原有功能的翻译。
